# 撮影会NOW — 無料・静的PWA版

Windows PCをサーバーとして起動し続けなくても使えるようにした静的PWA版です。
公開後は iPhone の Safari からアクセスでき、ホーム画面に追加できます。

## この版でできること

- NOW：現在時刻から「撮影中 / 移動中 / チェキ / 待機」を自動判定
- お気に入り出演者を最優先で横並び表示
- 出演者検索・1日の出演予定確認
- 会場マップ・エリア位置表示
- タイムテーブル表示
- イベントJSONの読み込み / 書き出し
- イベント・お気に入りをiPhoneのブラウザ内に保存
- 一度読み込んだ後のオフライン利用（PWAキャッシュ）

## 無料版で省いた機能

画像をアップロードしてクラウドAIで自動解析する機能は外しています。
新しい撮影会は、解析済みのイベントJSONを読み込んで追加します。

## いちばん簡単な公開方法：GitHub Pages

PCにPythonやDockerは不要です。GitHubのWeb画面だけで公開できます。

1. GitHubにログインして新しいリポジトリを作成します。
2. このフォルダの **中身** をすべてリポジトリ直下へアップロードします。
   - `index.html`
   - `app.js`
   - `logic.js`
   - `db.js`
   - `styles.css`
   - `manifest.webmanifest`
   - `sw.js`
   - `event-default.json`
   - `assets/`
   - `icons/`
   - その他同梱ファイル
3. リポジトリの **Settings → Pages** を開きます。
4. GitHub Pages の公開元を `main` ブランチ / ルートに設定します。
5. 公開URLが表示されたら、iPhoneのSafariで開きます。
6. Safariの共有ボタン → **ホーム画面に追加** を選びます。

GitHub Pagesの画面名や配置は将来変わる場合があります。その場合は「Pages」の公開設定を探してください。

## iPhoneで新しいイベントを追加

1. 右上の `＋` をタップ
2. イベントJSONファイルを選ぶ、またはJSONを貼り付ける
3. イベント名・日付・時間構成を確認
4. 出演者・エリアを確認
5. `端末に保存`

`event-template.json` は最小構成のサンプルです。

## データのバックアップ

右上の `…` → `JSONを書き出す` でバックアップできます。
端末を変える場合は、書き出したJSONを新しい端末で読み込んでください。

## 注意

- SafariのWebサイトデータを削除すると、端末内に保存したイベントやお気に入りが消える場合があります。大切なイベントはJSONでバックアップしてください。
- 初回表示にはインターネット接続が必要です。PWAキャッシュ完了後は、NOW・お気に入り・検索・同梱地図などをオフラインで利用できます。
- 画像解析はこの版では実行しません。
